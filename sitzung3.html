Sitzung 3: Digitale Objekte und Repositorien

Einleitung: In dieser Sitzung wird erklärt, wie digitale Objekte langfristig gespeichert und dauerhaft zugänglich gemacht werden können. Außerdem werden verschiedene Repositorien vorgestellt und ein erster Einblick in DSpace gegeben.

Offene und proprietäre Formate

Digitale Dateien können in offenen oder proprietären Formaten gespeichert werden. Offene Formate wie PDF oder PNG haben eine öffentliche Spezifikation. Deshalb können sie auch in Zukunft gelesen werden. Proprietäre Formate wie Microsoft Word oder Photoshop gehören einer Firma. Deshalb kann nicht garantiert werden, dass die Datei später noch genau gleich geöffnet werden kann. Für die Langzeitarchivierung sind offene Formate deshalb besser geeignet.

OCR (Optical Character Recognition)

Angenommen, ein altes Buch wurde eingescannt. Die Datei ist zwar digital, aber der Computer versteht zunächst nur 0 und 1 und erkennt den Inhalt nicht als Text. Für ihn ist der Scan nur ein Bild. Deshalb kann man später im Repository nicht einfach nach einem Wort suchen. Hier kommt OCR zum Einsatz. OCR erkennt die Buchstaben im Bild und wandelt den Scan in durchsuchbaren Text um. So kann der Inhalt später leichter gefunden und zusammen mit den Metadaten im Repository gespeichert werden.

Repository

Ein Repository ist eine digitale Plattform für wissenschaftliche Daten und digitale Objekte. Dort werden Dateien gespeichert, verwaltet und langfristig zugänglich gemacht. Ziel ist es, dass Informationen dauerhaft auffindbar und nutzbar bleiben. Dabei spielt Open Access eine wichtige Rolle, damit die Inhalte frei verfügbar sind.

Arten von Repositorien

Es gibt verschiedene Arten von Repositorien:

  • Institutionelles Repository: enthält alle Daten einer Institution oder Universität.
  • Disziplinäres Repository: enthält Daten aus einem bestimmten Fachgebiet.
  • Generisches Repository: kann Daten aus verschiedenen Bereichen speichern, zum Beispiel Zenodo.

Persistent Identifier

Jedes digitale Objekt sollte einen Persistent Identifier besitzen. Das ist ein dauerhafter Identifikator, mit dem ein Objekt jederzeit wiedergefunden werden kann. Auch wenn sich der Speicherort ändert, bleibt der Identifier gleich.

DSpace

DSpace ist eine Software zum Aufbau eines Repositoriums. Mit DSpace können digitale Objekte gespeichert, verwaltet und veröffentlicht werden. Außerdem können Benutzerrechte vergeben und Workflows für die Kontrolle der Daten eingerichtet werden.

Weiterführender Link: DSpace – Repository Software

Aufbau eines Repositoriums

Ein Repository organisiert digitale Objekte in einer klaren Struktur. Große Bereiche heißen Communities, darin befinden sich Collections und in den Collections werden die einzelnen digitalen Objekte (Items) mit ihren Dateien und Metadaten gespeichert. So bleiben alle Inhalte übersichtlich und leicht auffindbar.

Digitales Objekt

Ein digitales Objekt besteht nicht nur aus einer Datei. Es kann mehrere Dateien und zusätzlich Metadaten enthalten. Deshalb ist ein digitales Objekt mehr als nur eine einzelne Datei.

Dublin Core

Als Standard für Metadaten wird häufig Dublin Core (DC) verwendet. Dieser Standard definiert die wichtigsten Metadaten, damit digitale Objekte eindeutig beschrieben und leichter gefunden werden können.

Fazit

In dieser Sitzung habe ich gelernt, dass die Digitalisierung von Informationen allein nicht ausreicht. Digitale Objekte müssen in geeigneten Formaten gespeichert, mit Metadaten beschrieben und in einem Repository organisiert werden. Nur so können sie langfristig erhalten, leicht gefunden und wiederverwendet werden.
